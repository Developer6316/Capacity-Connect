# Capacity Connect

AI-powered smart learning platform for high school STEM students.

## Features
- AI Socratic Tutor (Gemini + NVIDIA NIM)
- Visual Homework Solver
- Spaced Repetition Flashcards
- Mock Exam Simulator
- Knowledge Graph & Mind Maps
- Gamified Learning with XP

## Tech Stack
- React 19 + TypeScript + Vite
- Express.js backend
- Google Gemini & NVIDIA NIM AI
- Tailwind CSS 4
- PWA for offline support

## Setup
1. Clone repo
2. `npm install`
3. Create `.env` with `GEMINI_API_KEY` and `NVIDIA_API_KEY`
4. `npm run dev`
5. Open `http://localhost:3000`
